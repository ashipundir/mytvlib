My TV Library

A personal movie and television browsing application.

About the Project

My TV Library is a personal project designed to explore movies and television shows through a simple, user-friendly interface.

The project is being developed for personal use on Android TV and Amazon Fire TV devices.

Features

• Movie and TV show discovery

• Search and browse categories

• Movie posters and descriptive information

• A television-friendly interface

• Remote-control navigation

Data Attribution

This project intends to use The Movie Database (TMDB) API to retrieve movie and television metadata.

This product uses the TMDB API but is not endorsed or certified by TMDB.
